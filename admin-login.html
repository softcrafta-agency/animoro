⚙️ Firebase Access

Animoro uses Firebase Authentication (Email/Password). To create your first admin:

  1. In Firebase Console, enable Email/Password under Authentication → Sign-in method.
  2. Under Authentication → Users, click Add user.
  3. Enter your admin email and a secure password.
  4. Set the Firebase web config values in your environment variables and redeploy.
