System Settings

Checking Firebase status...

Environment-based configuration

Firebase credentials are read from the Vite environment variables VITE_FIREBASE_API_KEY, VITE_FIREBASE_AUTH_DOMAIN, VITE_FIREBASE_PROJECT_ID, VITE_FIREBASE_MESSAGING_SENDER_ID, and VITE_FIREBASE_APP_ID. Add them to your local .env file or to the Vercel Environment Variables panel and redeploy.

Firebase project checklist

  1. Enable Email/Password authentication in the Firebase Console.
  2. Create or confirm the admins collection and add an admin document using the Firebase Auth UID as the document ID with { "role": "admin" }.
  3. Create the Firestore database and publish the rules below.
  4. Verify your public articles are read-only for visitors and that drafts remain admin-only.

Required Cloud Firestore Rules (firestore.rules)

Paste these rules into Firebase Console → Firestore Database → Rules tab to allow publishing and public reads.
