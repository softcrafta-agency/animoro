Step-by-Step Firebase Project Setup Guide

  1. Visit the Firebase Console and create a new project named animoro-blog.
  2. Under Build → Authentication, enable the Email/Password provider. Under Users, add your admin user email (e.g. softcrafta@gmail.com).
  3. Under Build → Firestore Database, click Create database in production mode.
  4. Under Build → Storage, click Get started to enable Firebase Storage for article cover uploads.
  5. Copy your Web App configuration snippet from Project Settings into the fields above or directly into js/firebase-config.js.
